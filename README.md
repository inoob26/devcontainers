# devcontainers

Reusable [Dev Container](https://containers.dev/) templates.

| Template | Description |
|---|---|
| [claude-python-devcontainer](claude-python-devcontainer/) | Python + uv + Claude Code, with docker-in-docker, ssh-agent forwarding and skills from `skills-list.txt` |

Copy a template's `.devcontainer/` folder into your project and reopen it in the container.
