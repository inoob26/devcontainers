# Claude Code skills installed into the container on every start by
# `install-skills.sh`. One GitHub URL per line, pointing at a folder that
# contains SKILL.md:
#
#   https://github.com/<owner>/<repo>/tree/<ref>/<path/to/skill>
#   https://github.com/<owner>/<repo>            # SKILL.md at the repo root
#
# <ref> is a branch, tag or commit SHA -- use a tag or SHA to pin a version.
# The skill is installed under the folder's name. Blank lines and `#` comments
# are ignored. Remove a line and the skill is removed on the next start.
